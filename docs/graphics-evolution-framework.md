# Public graphics evolution

The public runtime uses one versioned asset registry, `public/graphics/evolution-manifest.json`. The existing cinematic renderer owns the Earth and spatial layer. The registry applies reviewed scene artwork and keeps the visitor's chosen scene through the homepage and Products route during one browser session. Lumen's visitor interaction is implemented in its own controller.

## Add a visual

1. Prepare original motion, imagery or a model with authoring tools such as Runway, Blender or Unreal.
2. Verify source rights, spatial continuity, mobile crop, performance, captions and a still fallback.
3. Add the optimized export to the public asset directory and record its scene, origin category, accessibility description and review status in the registry.
4. Stage the exact source revision. Check the homepage and Products route with keyboard, touch, reduced motion and unavailable WebGL. Preserve the same information in text.
5. Promote reviewed source through the existing public release process with asset provenance and rollback evidence.

Sanity can supply reviewed public editorial direction after its visual records match the current source. Generated video and models become site assets only after review. The public registry contains no account credentials, customer information or private authoring paths.
